# Registros de Decisão de Arquitetura (ADRs)

Cada decisão técnica importante vira um ADR curto: contexto, decisão,
consequências. ADRs não são apagados; quando uma decisão muda, um novo ADR
a substitui e o antigo é marcado como "Substituído por NNNN".
